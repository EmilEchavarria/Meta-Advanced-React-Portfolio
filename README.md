# Advanced React Portfolio — Emil Echavarria

Peer-graded portfolio for the Coursera Meta **Advanced React** course.

## Features

- Fixed header with social links (GitHub, LinkedIn, email, portfolio) and smooth-scroll nav
- Header hides on scroll down / shows on scroll up (`translateY` + CSS transition)
- Landing section with avatar, name, and short bio
- Projects section: 2×2 card grid (OneDigs, IntelecMed, AgroGestor, DashBite)
- Contact Me form with **Formik + Yup** validation and **Chakra UI**
- Success alert toast on submit; form resets after successful submission

## Run locally

```bash
npm install
npm start
```

Or:

```bash
npm install
npm run dev
```

Then open the URL Vite prints (usually `http://localhost:5173`).

## Build

```bash
npm run build
```

## Stack

- Vite + React
- Chakra UI
- Formik + Yup
- react-icons
